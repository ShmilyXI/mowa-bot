# Changelog

## 0.3.0

### Forked from Aora Bot

- Mowa Bot starts from [Aora Bot](https://github.com/sam70361/aora-bot) 0.3.0, upstream commit `63c6c4f`, used under the MIT License.
- Renamed the project and every public name: packages `@aora-bot/*` → `@mowa-bot/*`, the `<aora-bot>` element → `<mowa-bot>`, `defineAoraBot` → `defineMowaBot`, `AoraBotElement` → `MowaBotElement`, `aoraBotId` → `mowaBotId`, CSS variables `--aora-*` → `--mowa-*`, data attributes `data-aora-*` → `data-mowa-*` and class names `aora-*` → `mowa-*`.
- Share links now use the `mowabot1.` prefix; links made on the Aora Bot site do not decode here.
- New logo and favicon. The sponsor page, the upstream author's payment codes and contact details, and the links to the classic Emotion Ball are removed.
- `NOTICE.md` records where the code comes from. `TRADEMARKS.md` is removed; the Aora Bot name and logo stay under the upstream trademark policy.

Earlier history is in the [Aora Bot changelog](https://github.com/sam70361/aora-bot/blob/63c6c4f/CHANGELOG.md).
