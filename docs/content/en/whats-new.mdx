# What's New

The changes in each release, newest first. Every package, export and parameter change is listed in full in the [changelog](https://github.com/ShmilyXI/mowa-bot/blob/main/CHANGELOG.md).

## 0.3.0

### Forked from Aora Bot

- Mowa Bot starts from [Aora Bot](https://github.com/sam70361/aora-bot) 0.3.0 by sam70361, used under the [MIT License](/guide/license).
- Every public name changed: the packages are `@mowa-bot/*`, the custom element is `<mowa-bot>`, and CSS variables use the `--mowa-` prefix.
- New logo and favicon.

Releases before the fork are described in the [Aora Bot changelog](https://github.com/sam70361/aora-bot/blob/63c6c4f/CHANGELOG.md).
