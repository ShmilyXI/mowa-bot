# 更新日志

各版本的变化，最新的在最前面。每个包、导出和参数的逐条变更见[完整变更日志](https://github.com/ShmilyXI/mowa-bot/blob/main/CHANGELOG.md)。

## 0.3.0

### 基于 Aora Bot

- Mowa Bot 基于 sam70361 所著 [Aora Bot](https://github.com/sam70361/aora-bot) 0.3.0 改造，按 [MIT 许可证](/guide/license)使用。
- 所有公开名称已更换：npm 包为 `@mowa-bot/*`，自定义元素为 `<mowa-bot>`，CSS 变量使用 `--mowa-` 前缀。
- 更换了标志和网站图标。

分支之前的版本变化见 [Aora Bot 变更日志](https://github.com/sam70361/aora-bot/blob/63c6c4f/CHANGELOG.md)。
